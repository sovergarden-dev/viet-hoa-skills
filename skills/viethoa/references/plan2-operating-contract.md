### Phương án 2 — external handoff / Antigravity

Hermes xuất ZIP translation-only tự đủ rồi dừng canonical writer. Hermes giữ extraction, deterministic technical gates, canonical merge, preview/import/repack/runtime; Antigravity chịu **toàn bộ công việc ngôn ngữ** theo hai phase có checkpoint lựa chọn: Phase 1 Parallel Preview-grade Draft → Hermes deterministic acceptance → hỏi user chọn hướng tiếp theo. Các route hợp lệ là demo patch, Phase 2 ngoài qua Antigravity, Phase 2 do Hermes cron, hoặc pause; demo không bắt buộc và Phase 2 ngoài chỉ là một lựa chọn. Route external dùng **Phase 2 Main-only Final Language & Semantic Review**. Phase 0 English-policy audit nằm trong preflight Phase 1 khi áp dụng, không thành lượt giao nhận riêng.

**Hai phase là baseline mới khi cần tăng tốc mà vẫn giữ một lượt final review toàn corpus.** Phase 1 dùng một main coordinator và các wave package-configured `1..12` worker có exact-key lease rời nhau; default ceiling `12`. Worker tạo preview-grade draft một lượt và silent self-review ngay trong response về fidelity, omission, natural Vietnamese, glossary/xưng hô, tokens/newlines, residual source và UI fit; không thêm reviewer agent. Mỗi full wave dùng **atomic wave**: controller `wave` expose tối đa configured `1..12` exact prompt cùng hash trong một wrapper recoverable, một native `invoke_subagent` call chứa exactly every staged worker entry chạy thật sự đồng thời, rồi `select` từng staged lease để direct-write/commit tuần tự. Không rolling refill và không dùng legacy `next` trong Phase 1; package cap chỉ là trần, không tự tạo concurrency. Mỗi worker `Prompt` là một JSON `agy-phase1-worker-invocation/v1` có đúng `schema,instructions,expected_prompt_sha256,response_schema,semantic_prompt`: `semantic_prompt` là nested prompt nguyên vẹn, `expected_prompt_sha256` là hash từ wave, `instructions` chứa `DO NOT CALL TOOLS`, `response_schema=agy-phase1-draft/v2`. Worker chỉ author preview-grade keyed output, không ghi shared state, không nested delegation, không `send_message|manage_subagents`; raw return phải là một bare UTF-8 JSON object hợp lệ với đúng bốn field `schema,batch_id,prompt_sha256,rows`; minified hoặc pretty-printed đều hợp lệ, nhưng BOM, code fence, prose và duplicate key bị cấm. Main direct-write raw worker bytes, không repair. Guard chỉ allow `select` sau exact wave reservation và chỉ allow raw write khi payload khớp byte-exact native worker transcript; event ghi `native_worker_conversation_id`. Controller được phép deterministic normalization duy nhất cho JSON serialization và top-level `agy-semantic-prompt/v1` sang `agy-phase1-draft/v2`; archive raw bất biến, receipt ghi `json_format|schema`, và mọi row/target UTF-8 bytes phải giữ nguyên qua `target_utf8_sha256_by_handoff_id`. Builder giữ hard prompt-byte cap trên từng lease và toàn wave; tăng tới 12 bằng worker count, không bằng phình dialogue lease hoặc bỏ context. Package controller có commit-time structural gate, chặn source-copy, edge whitespace, protected-token, locked-term và physical-newline mismatch trước khi commit; post-final check chỉ còn receipt verification, không tạo rework pass bình thường. Sequencing denial phải được deterministic-classify bằng `scripts/diagnose_guarded_phase1_recovery.py`; không đọc worker payload vào chat. Pinned controller là writer duy nhất. Hermes nhận một Phase-1 Master ZIP, lưu raw bytes bất biến, kiểm exact envelope/source/token/policy/lease evidence rồi tạo accepted parent snapshot. Phase 2 được build mới từ snapshot đó, chạy main-only cap `0` theo reverse/different order và review 100% corpus; high-risk/runtime-flagged/rewritten rows có targeted recheck trong cùng phase. Mỗi phase một outbound ZIP và một return ZIP; resume chỉ từ verified ledger của exact package/run.

**Receiver-control baseline hiện hành `AGY-VIETHOA-HANDOFF/2.5-TWO-PHASE-DRAFT12-PREVIEW-FINAL0-GUARDED`:** Phase 1 vẫn dùng exact lease, một main coordinator và package-configured cap `1..12`; current prompt bắt buộc mang package-pinned `lease_sha256` cùng complete `invocation_marker`; main bọc nested prompt nguyên vẹn trong `agy-phase1-worker-invocation/v1`, copy `prompt_sha256_by_batch` vào `expected_prompt_sha256`, rồi chỉ gửi wrapper JSON đó qua trường `Prompt` của worker. Phase 2 là main-only cap `0`. Cả hai phase còn phải host-arm `agy-semantic-origin-authorization/v3` bind exact package/run/manifest/controller/schedule/work paths trước khi Antigravity nhận task. Phase 1 bắt buộc host render bootstrap prompt riêng từ authorization đã materialize, nằm ngoài package/work, chứa exact JSON args `wave|select|commit|finalize`, current prompt/response paths và worker-wrapper contract; coordinator gọi `wave` trước, không đọc package docs khi chưa có current prompt. Builder phải cap actual canonical wave wrapper dưới receiver single-view budget; coordinator đọc đúng một lần, không `ContentOffset`/pagination, vì ghép nhiều trang có thể lệch/nhân row mà vẫn giữ hash cũ. Hai guard global của một Antigravity profile chỉ có một active package/run, nên re-check cả hai status ngay trước bootstrap; nếu package/run khác active hoặc semantic `main_conversation_id` đã bind thì giữ hàng đợi hoặc dùng profile/host tách biệt, không reset/arm chồng. Sau bootstrap, chỉ exact current prompt được đọc, exact controller commands và một native `write_to_file` vào current response được phép; helper script, `python -c`, shell chain, grep/find/list và mọi write khác bị deny. Phase 2 dùng `agy-explicit-review/v2`; ZIP chỉ lộ `challenge_slots`, còn actual challenge overlay nằm host-private ngoài package/work roots. Mỗi row có explicit decision đúng prompt order; recheck mọi rewritten/runtime/explicit high-risk cộng ít nhất stratified `10%` accepted theo domain/content/policy. Clean `keep_identity` là stratum riêng, không tự động thành high-risk toàn bộ. `2.4`, `2.3`, `2.2` và `2.0|2.1` chỉ còn historical-audit inputs.

**Token-boundary invariant:** “tối ưu/tiết kiệm token” ở Plan 2 nghĩa là giảm model work phía Hermes và bỏ thao tác/context lặp, không giảm exact-key coverage hoặc chất lượng final review. Hermes không dùng model để dịch, editorial review, semantic sample hoặc tạo language-QA remainder; chỉ chạy deterministic bytes/schema/key/source/token/state/hash/receipt gates. Dùng receipt-first, one-line summaries và các helper chung trong `token-efficient-external-handoff.md`; receiver-shell probe phải đạt trước arm.

- Manifest khóa authoritative source language, project origin/language evidence, name-provenance policy + ledger hashes, canonical identity `(domain,key)`, một output format/filename, exact key union/hashes, English-policy/glossary versions và immutable fields. Nếu provider cần một key, dùng `handoff_id` one-to-one manifest-pinned; không drop domain.

Phase 2 dùng `accepted|rewritten|needs_context`, nhưng final yêu cầu zero unresolved. Mỗi phase tạo snapshot/receipt mới có parent SHA-256, không ghi đè output trước.

Incoming Phase 1 là untrusted: lưu raw ZIP/hash, verify envelope/key union/source/token/policy/lease/host evidence rồi tạo Hermes-accepted derived snapshot; không merge canonical final. Incoming Phase 2 mới qua deterministic final gates và chỉ partial-merge khi whole envelope exact cùng từng hàng sạch độc lập. `scripts/accept_guarded_phase1_snapshot.py` phải emit `direct_phase2_eligible`, `recommended_next`, `allowed_next_routes` và exact `carry_blockers`. Đây là mandatory Phase-2 rewrite, không phải bỏ QA.
