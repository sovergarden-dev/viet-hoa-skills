## Reference router — lazy-load contract

Không đọc toàn bộ `references/`, `templates/` hoặc `scripts/` khi khởi động. Chỉ mở file được yêu cầu bởi nhánh công việc hiện tại; file tên game là case evidence, không phải default route.

**Load order:** `viethoa/SKILL.md` → đúng 1 reference nền tảng → case/reference bổ sung khi một gate hoặc engine match yêu cầu. Dịch mặc định đi Plan 1 qua `cron-tuning`. Khi thiết lập phong cách dịch hoặc kiểm tra ranh giới chống thuần-Việt-hóa khiên cưỡng, đọc `source-faithful-translation-policy.md`. Khi cần bàn giao dịch ngoài tổng quát hoặc xử lý ngoại lệ dính kiểm duyệt/18+/bạo lực, đọc `generic-external-agent-handoff.md`. Không đọc script source để hiểu quy trình nếu reference đã đủ; chỉ mở script khi cần chạy/audit/debug.

**Plan 1:** `translation-execution-modes.md` → `canonical-validation-and-merge-protocol.md` → `unattended-model-routing-and-prompt-budget.md`, rồi skill `cron-tuning` trước khi tạo job. Sau khi hoàn thành batch hoặc dịch xong, chạy `scripts/plan1_safety_detector.py` để quét rào cản kiểm duyệt và phân luồng (<= 15 dòng tự sửa qua `bientaptay`, > 15 dòng kích hoạt `bridge-plan2`).

**Plan 2 (Generic External Agent Handoff):** `generic-external-agent-handoff.md` → `scripts/external_agent_handoff.py`. Hỗ trợ: (a) Bàn giao toàn bộ từ đầu (`scope="full"`) khi game chắc chắn dính kiểm duyệt; hoặc (b) Bàn giao bù ngoại lệ từ Plan 1 (`scope="exception"`). Không chạy đồng thời cả hai phương án trên cùng một dự án. Antigravity di sản (`plan2-operating-contract.md`, `antigravity-two-phase-handoff.md`) chỉ dùng khi kiểm toán gói cũ.

**Engine/case:** chỉ mở nhóm Unity, Unreal, Adobe AIR hoặc case evidence sau khi fingerprint xác nhận engine/format. Trước import hoặc font, đọc `injection-ladder.md`. `buildpatch` chỉ load sau khi `viethoa` đã tạo artifact runtime-accepted.

**No duplicate skill profiles:** không tạo bản sao `viethoa-core/plan1/plan2`, symlink script, hoặc duplicate reference. Profile là load policy, không phải file copy; canonical skill và reference hiện tại là nguồn sự thật duy nhất.
