   - Copy `templates/installer-DESIGN.md` into the project as `DESIGN.md` and `templates/InstallerChassis.cs` as the starting `Program.cs` before UI restyling. Replace only the artwork-sampled accent, protected/safe rectangles, and `Engine` payload wiring. Tokens and chassis numbers stay normative.
   - Locked chassis, not a suggestion: borderless `1024 x 576`; full-bleed artwork; `Cài` and `Gỡ` adjacent on the same Y; build metadata in a fixed-width right-aligned cell; taskbar minimize via `ShowInTaskbar=true` + `WS_MINIMIZEBOX`; signature `Syrin.online` rainbow phase `0.045` in the bottom-right with an 8px inner margin; no extra footer.
   - Treat supplied artwork as composition, not wallpaper. Record protected logo/title/face/chin/focal rectangles and one or more safe UI rectangles at 1024x576. Controls stay inside a safe rectangle and never intersect protected art. Do not repeat a game title already present in the image.
   - Prefer one full-bleed image plus one compact dock in the lowest-salience safe zone. If no useful safe rectangle exists, use a bottom rail plus a native folder dialog. Do not invent centered glass cards, pills, purple/blue glow, decorative dots, fake versions or duplicate CTAs.
   - Single-file Win64 GUI with embedded payloads, manifest, artwork, icon and required licenses. One palette, one 4px radius, one icon family. Labels functional and short.
   - Always embed the application `.ico` and set `Form.Icon` in constructor plus dispatch native `WM_SETICON` (0x0080) for `ICON_SMALL` (0) and `ICON_BIG` (1) in `OnHandleCreated`. In `FormBorderStyle.None`, Windows uses `WS_POPUP` and does not automatically link the PE icon to the Taskbar or Alt-Tab switcher.
